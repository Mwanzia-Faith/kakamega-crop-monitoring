# Crop Condition Monitoring in Kakamega County, Kenya

**Status:** In progress

## Problem
How does crop vegetation respond to rainfall variability across
growing seasons in Kakamega County, and which seasons showed stress?

## Objectives
1. Build a cloud-masked NDVI time series for 3 growing seasons.
2. Classify cropland with Random Forest at 85% or higher accuracy.
3. Identify at least 2 stress seasons linked to rainfall.
